### QR CODE GENERATOR

Frontend web tool built with HTML, CSS, and JavaScript

This project is a lightweight browser-based tool that generates a unique QR code for any text or URL input by the user. It uses JavaScript and a public QR code API to dynamically render scannable codes in real-time .

💡 Features:

🖊️ Instant QR code generation from user input

🌐 Clean and responsive UI with HTML/CSS

🔄 Real-time DOM updates and external API integration

📸 Easy to scan with any mobile device

This tool showcases interactive web development, DOM manipulation, and third-party API usage — all in a compact and user-friendly interface. Great for anyone who wants to experiment with web utilities and data visualization on the client side! 🚀
